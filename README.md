### Parte 1 — Desafio Técnico Back-End: Engenharia de Dados com MongoDB

Marketplace simples em **Node.js + Express** com **armazenamento em memória**,
cobrindo cadastro de vendedores e compradores, anúncio de produtos, vitrine,
compras e cancelamento de pedidos.

A entrega implementa as quatro rotas do modelo inicial e inclui extensões
documentadas: consultas, atualização de anúncio e cancelamento de pedido.

- Código e instruções: [`README.md`](./Desafio%20T%C3%A9cnico%20Back-End%3A%20Engenharia%20de%20Dados%20com%20MongoDB%20-%20Parte%201/README.md)
- Visão geral do sistema: [`OVERVIEW.md`](./Desafio%20T%C3%A9cnico%20Back-End%3A%20Engenharia%20de%20Dados%20com%20MongoDB%20-%20Parte%201/OVERVIEW.md)

### Parte 2 — Desafio Técnico Back-End: Engenharia de Dados com MongoDB

Resposta com o passo a passo de teste da API no Postman/Insomnia: cadastro de
vendedor e comprador, anúncio de produto, consulta da vitrine e realização de
compra com redução de estoque.

- Resposta: [`Resposta.pdf`](./Desafio%20T%C3%A9cnico%20Back-End%3A%20Engenharia%20de%20Dados%20com%20MongoDB%20-%20Parte%202/Resposta.pdf)

### Parte 3 — Desafio Técnico Back-End: Engenharia de Dados com MongoDB

Marketplace com **Node.js + Express + MongoDB (Mongoose)**, com persistência dos
usuários, produtos e pedidos, validação de ObjectId e baixa de estoque atômica.

- Código e instruções: [`README.md`](./Desafio%20T%C3%A9cnico%20Back-End%3A%20Engenharia%20de%20Dados%20com%20MongoDB%20-%20Parte%203/README.md)

### Parte 4 — Desafio Técnico Back-End: Engenharia de Dados com MongoDB

Seed com **1.000 produtos, 5.000 usuários e 100.000 pedidos**, análise dos gargalos
sem índices secundários e criação de índices para as consultas mais comuns.

- Código e instruções: [`README.md`](./Desafio%20T%C3%A9cnico%20Back-End%3A%20Engenharia%20de%20Dados%20com%20MongoDB%20-%20Parte%204/README.md)
